## 1. 需求

## 3. 分类重命名能力

底层已有能力，**无需改 core**：

- `CustomizationStore.renameCategory(profileId, type, key, name)` 已在 `CustomizeViewModel.kt:339-343` 使用，`name = null` 或空串恢复 provider 原名。
- 直播分类的稳定 key：
  - `LiveKey.Folder` → `folderContextKeys.value[key.id]`
  - `LiveKey.Custom` → `key.id`
  - 两者正是 `LiveViewModel.categoryContextKey()`（`:300-304`）与 `contextKeyOf()`（`:724-730`）已维护的映射。
- 分类标题由 core `railCategories()` 返回 `displayName`，重命名后会自然生效，无需额外刷新逻辑。

在 `LiveViewModel` 新增：

```kotlin
/** Rename the long-pressed category; a blank name restores the provider's own. */
fun renameCategory(key: LiveKey, name: String?) {
    viewModelScope.launch {
        val pid = ctx.value.profileId.takeIf { it >= 0 } ?: return@launch
        val contextKey = categoryContextKey(key) ?: return@launch
        customize.renameCategory(pid, MediaType.LIVE, contextKey, name?.trim()?.takeIf { it.isNotEmpty() })
    }
}
```

UI 复用既有 `TextPromptDialog`（`settings/customize/CustomizeSupport.kt:54-90`），标题用 `settings_customize_rename`，初始值为当前显示名，`allowBlank = true` 以支持清空恢复原名。

### 4.2 分类长按菜单（`LiveCategoriesSheet.kt`）

`LiveCategoryMenu` 是 Live TV、Guide、点播库三处共用的 Composable：

| 调用点 | 文件 |
|---|---|
| 直播电视 | `LiveScreen.kt:396-411` |
| 电视指南 | `GuideScreen.kt:425-444` |
| 点播库 | `LibraryScreen.kt:385-400` |

为避免点播库被误伤，采用**可选回调**方式，菜单按传入回调决定显示项：

```kotlin
internal fun LiveCategoryMenu(
    title: String,
    onHide: () -> Unit,
    onDismiss: () -> Unit,
    onRename: (() -> Unit)? = null,          // 新增；非空才显示「重命名」
    onMove: ((MoveKind) -> Unit)? = null,    // 点播库继续传；直播/Guide 不传
    onRestore: (() -> Unit)? = null,         // 同上
    custom: Boolean = false,
    locked: Boolean? = null,
    onToggleLock: () -> Unit = {},
)
```

- 直播电视、Guide：只传 `onHide` + `onRename` → 菜单只剩「隐藏」「重命名」。
- 点播库：保持现有传参 → 菜单不变。

## 5. 影响面与风险

| 项 | 结论 |
|---|---|
| 共享组件 | `LiveCategoryMenu` 三处复用；用可选回调隔离，点播库不受影响 |
| 分类锁 | 直播/Guide 分类菜单不再提供「锁定/移除锁定」入口；设置 → 自定义里仍可管理，底层能力保留 |
| 分类排序 | 直播/Guide 不再提供分组排序入口；设置 → 自定义里仍可调整 |
| 恢复默认 | 直播/Guide 不再提供入口；设置 → 自定义里仍可恢复 |
| 频道隐藏 | 设置 → 自定义 → 隐藏频道仍可恢复（`CustomizeCategoriesPane.kt:140`） |
| 频道 EPG 匹配/偏移 | Guide 页仍保留，能力不丢 |
| 设置页菜单排序 | `ContentMenu.LIVE` 的 `catalogue()` 来自 core，设置 → 布局 → 内容菜单 → 直播电视仍会列出被删的 6 个 key。本次不改 core，接受「可配置但不再显示」的残留；如需同步隐藏，需在 app 侧对 `catalogue(ContentMenu.LIVE)` 加过滤 |
| 备份 / TV 互认 | 只改 UI 入口，不改存储 key；不受影响 |
| i18n | 删除的 `SheetAction` key 字面量会让 `safe_literals.txt` 出现陈旧记录，实施后按工具提示跑 `prune-safe` |
| 单测 | 现有测试未引用这两个菜单；实施后跑编译 + 设置搜索测试 + i18n 门禁 |
